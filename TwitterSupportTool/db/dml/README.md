# DML管理方針

このディレクトリは、Git管理してよい少量の初期データ・サンプルデータを置く場所です。

## 方針

- 大量データは `INSERT` 文にしてGit管理しない
- 実データ入りの `backup.dmp` はGit管理しない
- パスワード・認証情報・個人情報を含む可能性があるテーブルは原則コミットしない
- Git管理するDMLは、アプリ起動や検証に必要な最小限のマスタ・サンプルに限定する

## 注意

`TWITTERTOOLUSR.USER_MASTER` にはパスワード相当の列が含まれる可能性があるため、実データをそのままコミットしないでください。
必要な場合は、ダミーユーザー・ダミーパスワードへ置換したseedデータを作成します。
